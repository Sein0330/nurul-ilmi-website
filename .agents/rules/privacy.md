# ATURAN PRIVASI (WAJIB DIPATUHI)

Kamu DILARANG KERAS membaca, menulis, atau mengakses file berikut:
- `.env` dan semua variannya (`.env.*`)
- File `credentials.json` atau file JSON apapun yang mengandung credential
- File `*.pem`, `*.key`, `*.p12`, `*.pfx`
- File `id_rsa`, `id_ed25519`
- File `secrets.*` (yaml, json, dll)
- File `.npmrc`, `.pypirc`
- File `token.json`, `service-account*.json`

Jika kamu membutuhkan nilai dari file tersebut, MINTA user untuk memberikannya secara eksplisit. JANGAN pernah mencoba membaca file tersebut dengan alasan apapun.

Aturan ini berlaku MUTLAK dan tidak bisa dilanggar.
